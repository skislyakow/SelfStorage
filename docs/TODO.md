# Задачи

Открытые работы по проекту. Файл ведётся в git: `git pull` на любой машине — и актуальный список под рукой, ничего не теряется между сессиями и днями.

**Как продолжить работу**

- окружение: `./scripts/bootstrap.ps1` — uv sync, git-хуки pre-commit, локальные скиллы агентов;
- проверки: `README.md` → «Проверки» (тестам нужен `SECRET_KEY` в окружении);
- договорённости проекта и особенности окружения: `AGENTS.md`.

Приоритеты: **P1** — видит любой зритель, **P2** — заметно ревизору, **P3** — внутреннее качество.

## Инфраструктура и процесс

- [ ] **P2 · Деплой не гейтится CI:** `deploy.yml` срабатывает на push в `main` одновременно с `ci.yml`, а не после него. Вариант A: `on: workflow_run` (workflow `CI`, `conclusion == success`) плюс `concurrency`, чтобы деплои не накладывались. Вариант B: то же плюс деплой ровно проверенного SHA (`git fetch && git checkout <sha>`) — тогда на сервер не может уехать коммит новее проверенного. Для демо-стенда достаточно A.
- [ ] **P2 · Защитить `main`:** обязательный чек CI и запрет force-push. Делается в Settings → Branches (или Rulesets) либо через `gh api`, нужен доступ к GitHub.
- [ ] **P3 · Поставить `gh`:** статус прогонов сейчас проверяется запросами к API GitHub, из терминала было бы короче (`gh run watch`).
